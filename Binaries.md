# WhenToUse: Binarie Trees

## AVL

Situações Vantajosas:
- Latência de busca crítica;
- Atualizações pouco frequentes;
- Sistemas embarcados;
- Aplicações de extrema frequência de leitura;

## RB

Situações Vantajosas:
- Equelibrio geral;
- Usadas em sistemas reais: (Gerenciamento de RAM, Escalonadores, Sistemas de arquivos, estruturas de rede, Compiladores, ...);

## SkipLists

Situações Vantajosas:
- Simplicidade + Pararelismo;
- Bancos de dados modernos (NoSQL);
- Concorrência é prioritária;
- Sistemas distribuidos (Filas de prioridade distribuídas);
- Search Engines;
